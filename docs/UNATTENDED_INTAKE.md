# Unattended intake: operational contract

The Site now has a bounded `POST /api/automation/tick` job. It uses a separate `AUTOMATION_TICK_SECRET`, never editor sign-in. One invocation scans seven official source indexes (each at most once per UTC day), captures the newest eligible single-speaker current lead, and researches one newly extracted claim using separate supporting and contrary live searches. It records a private provisional assessment. If a source yields two claims, the other can be researched by a later invocation. It does not authenticate a source, approve a representation, lock materiality, adjudicate, publish, or produce a person score.

`automation_runs` records each UTC-hour slot, result, candidate, representation, and error. A unique slot prevents double runs. `AUTOMATION_DAILY_LIMIT` defaults to two job attempts per UTC day and cannot exceed five. `research_daily_budgets` atomically limits private bilateral model attempts to that same daily number, including ones started from the editor. A failed attempt counts so billing errors do not loop. This is an attempt cap, not a guaranteed dollar ceiling: model tokens and web-search calls vary. Captures and research drafts separately claim their own rows and record failure. The authenticated editor can inspect the latest runs at `/api/editor/automation-status` and in the workspace. Every cited URL remains an unverified lead.

## Complete deployment

1. Supply a scheduler that can reach the Site's worker without a human browser session. `ops/scheduled-intake` is a Cloudflare Cron Trigger adapter set to 13:00 and 19:00 UTC. Provision it in a Cloudflare account and store `ON_RECORD_URL` and `ON_RECORD_TICK_SECRET` as worker secrets. The same random secret must be stored as the Site's `AUTOMATION_TICK_SECRET`. Do not put secrets in the repository or a chat prompt.
2. Resolve Site ingress. This owner's current custom-access Site responds 401 to an external request **before the app's token check**. The platform's exposed bypass value did not work as a normal Authorization bearer. Keep the private audience until a supported service-to-service access mechanism is confirmed. An alternative is to move the public-facing Site to its intended public audience while retaining editor authentication and the separate tick secret. Do not silently change audience for a test.
3. Redeploy the Site after setting its secret. Deploy the scheduler and invoke it once; verify a COMPLETE or an actionable FAILED row, capture state, draft citations, and actual model usage. Confirm repeated calls within the hour return ALREADY_RUNNING_OR_COMPLETE and the daily cap returns DAILY_LIMIT. Then monitor the run ledger and billing. A deployed code path by itself is not unattended operation.

The current source set covers official HTML/text statements. Original social posts, audiovisual media, transcripts with multiple speakers and OCR require source-specific adapters and provenance checks. Older seven candidates extracted before the stronger prompt are deliberately excluded from scheduled research; an editor can re-extract substantive claims from their preserved originals.
