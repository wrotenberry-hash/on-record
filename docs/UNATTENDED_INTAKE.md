# Unattended intake: operational contract

The app has a bounded `/api/automation/tick` job. Vercel Cron calls it with GET and the `CRON_SECRET` bearer; a manual POST uses `AUTOMATION_TICK_SECRET`. It never uses editor sign-in. One invocation scans seven official source indexes (each at most once per UTC day), captures the newest eligible single-speaker current lead, and researches one newly extracted claim using separate supporting and contrary live searches. It records a private provisional assessment. If a source yields two claims, the other can be researched by a later invocation. It does not authenticate a source, approve a representation, lock materiality, adjudicate, publish, or produce a person score.

`automation_runs` records each UTC-hour slot, result, candidate, representation, and error. A unique slot prevents double runs. `AUTOMATION_DAILY_LIMIT` defaults to two job attempts per UTC day and cannot exceed five. `research_daily_budgets` atomically limits private bilateral model attempts to that same daily number, including ones started from the editor. A failed attempt counts so billing errors do not loop. This is an attempt cap, not a guaranteed dollar ceiling: model tokens and web-search calls vary. Captures and research drafts separately claim their own rows and record failure. The authenticated editor can inspect the latest runs at `/api/editor/automation-status` and in the workspace. Every cited URL remains an unverified lead.

## Complete deployment (Vercel, since 2026-09-26)

1. `vercel.json` declares two cron entries for `/api/automation/tick` at 13:00 and 19:00 UTC. Vercel provides `CRON_SECRET` as a project environment variable; the job refuses any call without it. On the Hobby plan a cron may fire anywhere within its scheduled hour, which the hour-slot ledger tolerates.
2. Set `CRON_SECRET`, the Turso and Supabase settings, `EDITOR_EMAILS` and `OPENAI_API_KEY` in Vercel, then deploy. `GET /api/automation/health` reports which secrets are bound without revealing them.
3. Verify a COMPLETE or an actionable FAILED row in `automation_runs`, the capture state, the draft citations and actual model usage. Confirm a second call within the hour returns ALREADY_RUNNING_OR_COMPLETE and a third call in the day returns DAILY_LIMIT. Then monitor the run ledger and OpenAI billing. A deployed code path by itself is not unattended operation.

The current source set covers official HTML/text statements. Original social posts, audiovisual media, transcripts with multiple speakers and OCR require source-specific adapters and provenance checks. Older seven candidates extracted before the stronger prompt are deliberately excluded from scheduled research; an editor can re-extract substantive claims from their preserved originals.
