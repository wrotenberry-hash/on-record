Packet: `packets/HR915.txt` (read in full). Sources used: CITED Sec. 2, SOURCE CRS, SOURCE FLOOR, SOURCE REPORT, SOURCE STATUS, SOURCE CBO, CONTEXT, HEADINGS. Nothing outside the packet was used.

**VERDICT: MISSTATES** (one borderline CORE misstatement; everything else MINOR)

Counts: CORE 1 MISSTATES, 8 MINOR. EXTENDED 0 MISSTATES, 7 MINOR.

## CORE findings

### C1. howItWorksToday item 3 — CONDITION DROPPED (and one member's figure given as plain fact) — MISSTATES (borderline)
- Summary: "In 2026, the program had made more than 38,000 loans worth more than $20.3 billion. The average loan was about $533,000."
- Source (FLOOR, Rep. Olszewski, speaking June 23, 2026): "Thus far, in 2026, the program has originated more than 38,000 loans worth more than $20.3 billion with an average loan size of approximately $533,000."
- Why: "Thus far" (a count up to 23 June 2026, under six months) is dropped. A reader sees a 2026 figure with no as-of point, and elsewhere in the same summary sees "more than 78,000 loans worth more than $37.2 billion last year", so the program appears to have roughly halved. "had made" hints at a cut-off but none is given. "more than" keeps it literally true, which is why this is borderline; downgrade to MINOR if a partial-year count without its date is acceptable. "about" correctly keeps "approximately".
- Also: the figures are one member's floor statement, shown without credit (only the section tag "FLOOR").

### C2. plainEnglish, sentence 1 — WRONG CREDIT (one member's claim stated as plain fact) — MINOR
- Summary: "Small businesses can already use the main federal small-business loan guarantee program for software and cloud computing, but some businesses still report confusion about that."
- Source (FLOOR, Rep. Olszewski): "small businesses have been able to utilize 7(a) loans to finance digital tools, including software and cloud computing services. The SBA further clarified that position last June, yet some businesses have still reported uncertainty about using 7(a) loans for these purposes."
- Why: the only source that says loans can already be used this way is Rep. Olszewski. Other sources describe the present position as unclear: Rep. Alford (FLOOR) "there has been unnecessary uncertainty about whether these investments qualify as eligible business expenses"; REPORT "eliminates ambiguity ... by clarifying that the SBA can provide 7(a) loans". The summary states it as settled fact with no credit. Not shown false by the packet, so MINOR.

### C3. howItWorksToday item 4 — WRONG CREDIT / NO SOURCE for the year / word softened — MINOR
- Summary: "The agency clarified in June 2025 that these loans can finance business software or cloud computing services. Some businesses still reported uncertainty."
- Source (FLOOR, Rep. Olszewski, June 23, 2026): "Last June, the SBA further clarified that 7(a) loans could be used to finance business software or cloud computing services. However, some businesses have still reported uncertainty about using 7(a) loans for these purposes."
- Why: (a) "June 2025" is not stated anywhere; it is inferred from "Last June" said on 23 June 2026 (a reasonable reading, but an inference). (b) "further clarified" becomes "clarified", losing that this was an additional clarification of an existing position. (c) one member's statement given as plain fact.

## EXTENDED findings

### E1. whatItDoes item 3 — EXACT WORD CHANGED — MINOR (borderline)
- Summary: "Includes business tools that use artificial intelligence, but does not allow these loans for research and development."
- Source (Sec. 2(b)(2)): "Nothing in the amendment made by subsection (a) shall be construed to ... authorize the use of loans made under section 7(a) ... for research and development purposes".
- Why: the source is a rule of construction: this amendment is not to be read as authorizing R&D use. "does not allow these loans for research and development" can be read as a prohibition on R&D use of these loans, which the text does not state. The changes row has the accurate form ("does not authorize"). Rated MINOR because "the bill does not allow" can also be read as "does not grant permission".

### E2. whoItAffects item 2 — WRONG CREDIT — MINOR
- Summary: "Participating lenders, because the bill gives clearer legal authority for loans that finance listed business technology." (tag: "Sec. 2")
- Source (FLOOR, Rep. Alford): "It simply provides clarity so that lenders and small business owners can move forward with confidence."
- Why: Sec. 2 does not mention lenders or clarity; the effect on lenders is Rep. Alford's claim, given as plain fact under a Sec. 2 tag.

### E3. whatChangesForYou, sentence 2 — WRONG CREDIT — MINOR

### E4. whatChangesForYou, sentence 1 — NO SOURCE (invented example) — MINOR

### E5. unknowns item 1 — ABOUT THE SOURCES — MINOR

### E6. unknowns item 2 — ABOUT THE SOURCES + NO SOURCE (presupposition) — MINOR
